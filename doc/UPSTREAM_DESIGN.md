## 0. 何を根拠に書いているか

根拠は 3 つだけ: **師匠の言葉（原文）**・README・`LESSONS_FROM_THE_FIRST_CONSUMER.md` の実測。
どれにも辿れない項目は「⚠ AI 判断」と明記する。他のプロジェクトは参照していない（師匠の規則）。

### 師匠の言葉（原文・2026-09-21）

> このプロジェクトは、入力した命題に対して客観的判定を行うこと。そして判定出力（スカラー）を適切な分布の連続量ないし離散値として得られること。
> その方法として内部的には対立を含む複数の問いに対してLLMで答えさせ、その分布から出力値を作るというコンセプト。
> それが実現できる汎用ライブラリであること。

> 例えば「羅生門」において「老婆は悪人である」の度合いを１～５で示せ。というような命題に対して答えが出ること。

> 基本的には判定に必要な全文を入力する（LLMの知識に頼らない）。
> 問いの集合もLLMが生成することを基本と考える。よって問いの生成ルールやそれを規定するハーネスもこのプロジェクトに含まれる。
> 適切な分布は(b) 一つの出力が幅を伴って返ることを示す。
> その分布の確からしさ、コンフィデンスレベルも添えられればなおよい。
> 対立を含むは、LLMの偏りを打ち消すことを目的とする。Y,N両方の観点から問い、Y,Nが割れるのか、偏るのかを判定する。なので軸の撮り方は命題次第。

## 1. 一行で

> **本文と命題を受け取り、支持・反証の両観点から問いの集合を LLM に立てさせ、各問いを本文の根拠つきで答えさせ、
> その答えの分布から「度合い ＋ 幅 ＋ 診断値」を、宣言した型の中で返す。読み手ごとに返し、読み手間の差を隠さない。**

羅生門の例で言えば: 本文（全文）と「老婆は悪人である」と「1〜5」を渡す →
「老婆は死体から髪を抜いたか」（支持観点）「老婆は生きるためにやむを得ないと語ったか」（反証観点）…という問いが立つ →
各問いに Yes / No / 判定不能 と本文中の根拠（文の id）が返る → 支持 s 軸・反証 r 軸から度合いと幅が出る → 1〜5 の段が返る。

## 2. 用語（師匠の語彙を正とする）

| 語 | 意味 |
|---|---|
| **命題** | 判定したい主張。自然言語 1 文（例: 「老婆は悪人である」） |
| **本文** | 判定に必要な全文。LLM の知識に頼らず、ここに無いことは判定不能 |
| **単位** | 本文を機械的に割った文または段落。短い ASCII の id を持つ。根拠は単位の id で指す |
| **問い** | 本文の内容について判定できる 1 文。LLM が命題から生成する。⚠ 形は疑問文ではなく**記述（平叙文）**にする（§5.1。否定形の疑問文への Yes / No は日本語で二通りに読め、対の矛盾率が言語慣習で汚れる。空撃ち 1 周目で実測 0.60 → 記述化で 0.00） |
| **記述** | 問いの実体。軸の両側の平叙文（支持側「計画していた町をすべて訪れた」／反証側「訪れなかった町があった」）。互いに排他 |
| **軸** | 命題の真偽に関わる 1 つの事柄。1 軸 = **互いに排他な記述の対**（支持側・反証側）。**軸の取り方は命題次第** |
| **観点（Y / N）** | 軸の両側。**支持側**の記述は本文がそう述べていれば命題を支持し、**反証側**の記述は本文がそう述べていれば命題を反証する |
| **対立** | 各軸が支持側と反証側の記述を持つこと。目的は **LLM の偏りを打ち消す**こと（両側に証拠が出た軸は矛盾として数える）。⚠ v2 の「支持観点と反証観点の記述を同数」は空撃ちで崩れた（§6 H1） |
| **分布** | 答えの集まり（回答行列）と、そこから作る度合いと幅 |
| **割れる / 偏る** | 両観点の答えが拮抗する（割れる）か、片側に寄る（偏る）か |
| **度合い** | 有効な軸のうち支持側に倒れた割合 ∈ [0, 1] |
| **幅** | 1 つの出力に伴う分布の広がり。**本文の中で命題がどれだけ争われているか**を表す。⚠ **軸数に依存しない量**でなければならない（§7.3） |
| **確からしさ（コンフィデンス）** | 幅とは別。**この判定という計測がどれだけ信用できるか**（計器の側の量）。v1 は診断値の組として返す |
| **型** | 利用側が宣言する出力の形（真偽確率 / 順序尺度 / ラベル集合）。値は型の外に出ない |
| **読み手** | 問いに答える LLM。複数（≥ 2）で回し、差が出たら仕組みの欠陥として扱う |
| **生成器** | 問いを生成する LLM。読み手と同じでも別でもよい。名前を記録する |
| **偽読み手** | 較正用の決定論の読み手（全問 Yes・全問 No・全問 判定不能・乱数）。既知の不良を不良と読めるかを見る |

## 3. ドライバ

### 3.1 品質特性（設計が狙うもの）

| # | 品質特性 | 何を意味するか | 出どころ |
|---|---|---|---|
| Q1 | **読み手非依存** | 同じ本文・命題・問いの集合で読み手（モデル）を替えても、度合いと段が同じ。差が出たら欠陥 | 師匠「客観的判定」／LESSONS §2・§6.5 |
| Q2 | **型の閉包** | 出力は宣言した型の中にしか存在しない。パース不要・形式崩れ無し | README「これは何か」 |
| Q3 | **偏りの打ち消し** | 両観点の問いを置き、LLM の一律の偏り（肯定に寄る等）が度合いに残らない。⚠ **残ったときに検出できる**ことを含む（§7.5・S11） | 師匠「対立を含む…偏りを打ち消す」 |
| Q4 | **幅と確からしさ** | 1 出力に幅が付く。幅は軸数に依存しない。確からしさは数えられる量から作り、LLM に申告させない | 師匠「一つの出力が幅を伴って返る」「コンフィデンスレベルも添えられれば」 |
| Q5 | **検証可能性** | どの軸がどちらに倒れ、本文のどの単位を根拠にしたかが記録に残り、事後に本文と突き合わせられる | README 問題 3／LESSONS §4・§6.2 |
| Q6 | **汎用性** | 本文・命題・型を渡せばどのドメインでも動く。ライブラリは利用側を import しない。段の意味づけも利用側 | 師匠「汎用ライブラリ」／README 約束 1〜4 |
| Q7 | **再計算可能** | LLM の生応答と本文の単位列が残り、集約は決定論で何度でも引き直せる | ⚠ AI 判断（Q5 と「テストは単体で走る」から導出） |
| Q8 | **費用の可視性** | 1 判定に何回 LLM を呼んだかが返る。上限は利用側が宣言する | ⚠ AI 判断（レイヤー 3 の動機「生成税」の前段） |
| Q9 | **本文追従** | 判定は本文に従って動き、LLM の記憶で答えない。本文の事実を変えれば判定が変わる | 師匠「判定に必要な全文を入力する（LLMの知識に頼らない）」 |

### 3.2 制約

- **Python**（師匠）
- **本文は入力**。外部取得も LLM の知識も使わない（師匠）
- **問いは LLM が生成**し、生成の規則とハーネスは本ライブラリの中（師匠）
- **依存は一方向**。利用側を import しない。ドメイン語彙は型として利用側から渡す。テストは単体で走る（README）
- **読み手は差し替え可能**で、少なくとも 2 つで回せること（Q1 を測るため）。偽読み手も同じ口に差せること（S11）
- 蒸留は後段。ただし**記録の形は蒸留の素材になる**ように今から決める（§8）

### 3.3 主要な使い方（README「使いどころ」）

高頻度の分類・重大度評価／生成のガードレール／構造的フィードバック（どの軸で落ちたか）／高密度フィルタリング。
v1 が直接支えるのは最初の 3 つ。高密度フィルタリングは費用が下がる蒸留後。

## 4. 入出力契約（外側）

順序ではなく「何が何に変換されるか」で書く。

### 4.1 入力 — 判定依頼

| 項目 | 内容 | 誰が決めるか |
|---|---|---|
| 本文 | 判定に必要な全文（テキスト）。1 回の文脈に入る長さ（超えたら失敗 F1） | 利用側 |
| 命題 | 自然言語 1 文 | 利用側 |
| 型 | 真偽確率 `[0,1]` ／ 順序尺度（段数 K ≥ 2、任意で段のラベル、**任意で段の境界**。既定は K 等分 ⚠ 仮置き）／ ⚠ ラベル集合（v1 は対象外。§10） | 利用側 |
| 読み手 | 1 つ以上の LLM（≥ 2 を推奨。偽読み手も可） | 利用側 |
| 生成器 | 問いを生成する LLM。省略時は読み手の先頭 | 利用側 |
| 予算 | 軸数の**下限と上限**（観点ごと）・読み手ごとの標本数・生成の再試行上限・呼び出し粒度（既定: 1 問 1 呼び出し ⚠ J13） | 利用側（既定は保守的） |
| 判定の閾値 | 割れ/偏り・根拠不足・計器不良の閾値（§7.4）。既定は ⚠ 仮置き。実データが溜まったら分位点で引き直す（§13） | 利用側（既定あり） |

### 4.2 出力 — 判定結果

読み手ごとの判定と、読み手をまたぐ要約の 2 段で返す。

**読み手ごと**（読み手 × 1 件）:

| 項目 | 内容 |
|---|---|
| 度合い | 有効な軸のうち支持側に倒れた割合（§7.2） |
| 幅 | 支持と反証の拮抗の度合い ∈ [0, 1]。軸数に依存しない（§7.3） |
| 札 | `偏り（支持）` / `偏り（反証）` / `割れる` / `本文に根拠が無い` / `計器不良` の 5 値（§7.4） |
| 値 | 型の中の値（真偽確率なら度合い、順序尺度なら段）。札が `本文に根拠が無い` / `計器不良` のときは**値なし** |
| 診断値 | 観点ごとの有効率・判定不能率・記述なし率・無効率・標本間の一致率・追加生成の回数（§7.5） |

**読み手をまたぐ要約**:

| 項目 | 内容 |
|---|---|
| 読み手間の差 | 読み手ごとの度合いの最大値 − 最小値。段の一致／不一致。**一級の出力**（Q1 の計器） |
| 代表値 | ⚠ 未決 U3。v2 の仮置きは読み手ごとの度合いの平均と、それが落ちる段 |
| 監査記録 | 問いの集合（観点つき）・本文の単位列・回答行列（答え・否定の型・根拠 id・有効/無効）・生成器と読み手の名前・指示の版 |
| 費用 | LLM 呼び出し回数（生成／追加生成／回答。キャッシュ命中／実呼び出し） |

⚠ **幅と確からしさは別の量。** 「争われている命題」は幅が広く、根拠は十分（有効率が高い）、ということがありうる。
「本文に根拠が乏しい」は幅ではなく**札と診断値**に出る（§7.4）。
⚠ v1 は確からしさを **1 つの数に畳まない**。畳む式は未較正で、較正されていない数は較正されている顔をする。

### 4.3 API の形（⚠ AI 判断・仮）

```python
judge(material: str, proposition: str, output: OutputType,
      *, readers: Sequence[Reader], planner: Reader | None = None,
      budget: Budget = Budget(), thresholds: Thresholds = Thresholds()) -> Judgment
```

`Judgment` は §4.2 の各項目を属性として持つ。公開 API はこの 1 本から始め、増やすときは理由を書く。

### 4.4 失敗と縮退

「型付きエラーで拒否」か「縮退して札と診断値で返す」かを、失敗ごとに決める。

| # | 失敗 | 扱い | 理由 |
|---|---|---|---|
| F1 | 本文が 1 回の文脈に入らない | **拒否**（型付きエラー） | 師匠「判定に必要な全文を入力する」— 入らない本文は入力が成立していない。分割は判断を生成に委ねる経路なので別の題として設計する（⚠ J12） |
| F2 | 本文が空・命題が空・K < 2・軸数の下限 > 上限 | **拒否** | 入力の契約違反 |
| F3 | 問い生成が再試行上限までに H1〜H8 を満たせない | **拒否** | 生成器の失敗を値に化けさせない。診断値に生成の試行回数と違反した規則を残す |
| F4 | ある読み手で有効な軸が 0（s + r = 0） | **縮退**: その読み手の札 = `本文に根拠が無い` または `計器不良`（無効率で分ける）、値なし | 除算が未定義。値を作らず札で返す |
| F5 | 読み手が 1 体 | **縮退**: 読み手間の差は「単読み手」と明記して欠測 | Q1 は測れないが判定はできる。欠測を 0 で埋めない |
| F6 | 読み手ポートが再送 1 回でもスキーマに合わない | その問い・標本を**無効**として数え、判定は続行。無効率が閾値を超えたら札 = `計器不良` | 1 件の形式崩れで全体を落とさない。ただし無効は黙って捨てず数える |
| F7 | 命題が複合文（「老婆は悪人で下人は善人である」） | v1 は**検出しない**（§10）。利用側が 1 文にする | 検出も判断なので v1 では約束しない |

## 5. 内部の変換（層）

各層は「IN → OUT」で定義し、順序は依存関係からだけ決まる。概念文書のレイヤーとの対応も書く。

| 層 | IN → OUT | 性質 | 概念文書 |
|---|---|---|---|
| **L0 読み手ポート** | (指示, 回答スキーマ, モデル名) → スキーマ準拠の回答 **または** 型付きエラー | LLM は確率的。**形式は決定論で守る**（ネイティブ指定 ＋ 指示への明記 ＋ 受信検証、失敗は再送 1 回 → 型付きエラー） | — |
| **単位化** | 本文 → 単位列（文または段落。短い ASCII の id 付き） | **決定論**（コード）。規則は版付き | — |
| **L1 問い生成** | (本文, 命題, 予算) → 問いの集合 | 確率的。**ハーネス（§6）が形を強制** | レイヤー 1 |
| **L2 回答** | (単位列, 問いの集合, 読み手, 標本数, 粒度) → 回答行列（答え ＋ 否定の型 ＋ 根拠 id ＋ 有効/無効） | 確率的。**根拠 id の実在は決定論で照合** | レイヤー 2 |
| **L3 集約** | 回答行列 → 読み手ごとの（度合い・幅・札・診断値）＋ 読み手間の差 | **決定論** | レイヤー 2 |
| **L4 型付け** | 度合い ＋ 型 → 値 | **決定論**。構造的に型の外へ出ない | レイヤー 2 |
| L5 蒸留 | 記録（§8）→ 特化モデル | 後段 | レイヤー 3 |

**判断が LLM に委ねられているのは L1・L2 の中身だけ。** 形（スキーマ・対称性・根拠 id の実在）と集約は全部コードが持つ。
揺れる場所は判断を生成に委ねている場所と一致する（LESSONS §1）ので、委ねる範囲をここに閉じ込める。

### 5.1 問いの集合（L1 の OUT）

問い 1 件が持つもの:

| 項目 | 内容 |
|---|---|
| id | 決定的な短い ASCII 識別子 |
| 軸 | 観点の短い名（例: `死体からの盗み`）。**人が読むためのもの。測定には使わない** |
| 支持側の記述 | 平叙文。本文がそう述べていれば命題を支持する。**本文中の出来事・発話・記述の有無**で決まる文。評価語で書かない。疑問文にしない |
| 反証側の記述 | 同じ事柄について、本文がそう述べていれば命題を反証する平叙文。支持側と**互いに排他** |

⚠ **軸は本文に書かれているかどうかで選ばない。** 命題の真偽を分ける事柄を選ぶ。本文が触れていない軸が混ざってよい（それは「触れていない」として数えられる）。
v2 の形（支持観点の記述 4・反証観点の記述 4）は、本文を読める生成器が両側とも「述べられている真の事実」で枠を埋めるため、
度合いが構造的に 0.5 になった（空撃ち p2: 22 件中 15 件が p=0.50）。対の形では本文が対称性を破る（p3: 想定に合った題材 10/11）。
| 出自 | `初回生成` / `追加生成`（H1 の不足補充で生まれた問いか） |

### 5.2 回答（L2 の OUT）

回答 1 件（問い × 読み手 × 標本）が持つもの:

| 項目 | 内容 |
|---|---|
| 答え | 本文と記述の関係の 3 値: `述べている`（＝Yes） / `否定している`（＝明示的否定の No） / `触れていない`（＝判定不能）。「記述が無い」は独立した値なので、沈黙が No に化ける経路が構造的に無い（H9） |
| 根拠 | `述べている` / `否定している` のとき必須。**本文の単位の id**（1 つ以上）。逐語引用は任意（照合には使わない） |
| 有効 | 根拠 id を**正規化してから**（角括弧・空白を除く）単位列と照合し、すべて実在すれば有効。1 つでも実在しなければ**無効**（判定不能とは別に数える） |

⚠ 根拠を要求するのは `述べている` と `否定している` だけ。「触れていない」に根拠を求めない。
⚠ 根拠を**逐語引用ではなく id** にするのは、本文が日本語だと逐語転写が崩れ、捏造と転写ずれが区別できないため（LESSONS §6.1 の「較正できる計器」を保つ）。
⚠ id も転写される。空撃ち 1 周目では無効 6 件中 5 件が「`[s5]`」と角括弧付きで返っただけで、捏造ではなかった。**照合の前に正規化する**（正規化しても一意性は落ちない）。

### 5.3 方向（L3 の入口）

軸の両側の答え（v_支持, v_反証）から方向 d ∈ {+1, −1, 0} を決める（⚠ AI 判断 J3・J17）:

    支持側に証拠 ＝ v_支持 == 述べている または v_反証 == 否定している
    反証側に証拠 ＝ v_反証 == 述べている または v_支持 == 否定している
    両方        → 矛盾（d = 0。u₄ として数える。読み手の偏りか、対が排他でなかったかのどちらか）
    支持側だけ  → d = +1
    反証側だけ  → d = −1
    どちらも無い → d = 0（沈黙。u₁）
    無効を含む  → d = 0（u₂）

同じ読み手の標本が複数あるときは、**問いごとに多数決**で方向を決め、一致率を診断値に残す。同数なら 0（`標本同数`として数える）。
**読み手をまたぐ多数決はしない。** 読み手ごとに §7 を独立に回す（⚠ J14。v1 の「読み手をまたぐ多数決」は Q1 の信号を潰していた）。

## 6. 問い生成ハーネス（L1 の規則）

生成は LLM、規則の検査はコード。**指示（プロンプト）は版付きの外部ファイル、規則はコード**（⚠ J9）。

| # | 規則 | 内容 | 検査 | 出どころ |
|---|---|---|---|---|
| H1 | **各軸が両側を持つ** | 各軸に支持側と反証側の記述があり、互いに排他 | 機械（両側が空でない・同一でない）。⚠ 排他性そのものは未検査（両側に証拠が出た軸が矛盾として現れる。p3 で矛盾率 0.11〜0.12 のうち一部は非排他な対） | 師匠「Y,N 両方の観点から問い」。⚠ v2 の「同数」は p2 で崩れた |

評価は割った問いの分布から**コードが**作る。生成指示で禁じるだけでは守れないことは分かっているが、
守られたかを機械で見る手段がまだ無い。§10 に限界として書き、S5 で人が測る。

複数生成器の和集合・交差は実験の結果で決める（§12 の保留）。

## 7. 分布・出力値・診断値（L3・L4 の規則）

すべて**読み手ごと**に計算する。

### 7.1 数える

問いごとの方向（§5.3）を集計する:

| 記号 | 内容 |
|---|---|
| s | 方向 +1（支持）の軸数 |
| r | 方向 −1（反証）の軸数 |
| u₁ | 判定不能・記述なし（**本文が沈黙**） |
| u₂ | 無効（根拠 id が実在しない ＝ **計器の問題**） |
| u₃ | 標本同数 |
| u₄ | 矛盾（軸の両側に証拠。読み手の偏りか、対が排他でなかったか） |
| n | s + r + u₁ + u₂ + u₃ + u₄ |

観点ごとにも数える（支持観点側の s+r / その観点の軸数、反証観点側の同）。**片側性**はここに出る（LESSONS §5.4）。

### 7.2 度合い（⚠ J4′）

    度合い p = s / (s + r)        （s + r > 0 のとき。0 のときは F4）

すべての軸は等重み（⚠ 未決 U2）。重みを LLM に申告させない。

### 7.3 幅（⚠ J4′）

    幅 w = 2 · min(s, r) / (s + r)        ∈ [0, 1]

w = 0 は全軸が一方向、w = 1 は完全に拮抗。**軸数に依存しない**（s, r を同じ比で倍にしても変わらない）。

⚠ v1 の幅（Beta 分布の区間）は軸数だけで狭まり、同じ本文でも予算を倍にすれば幅が半分になった。
それは本文ではなく予算の性質なので捨てた。**「軸数を倍にしても幅が変わらない」を品質シナリオ S12 で要求する。**
⚠ 軸は独立ではない（同じ命題から LLM が立てた問い）。w は比なので独立性を仮定しないが、
意味の重複した軸は s か r を偏らせうる。H4 の意味の重複は未検証（§10）。
⚠ 順序尺度の「各段の確率」は v1 では返さない。軸数に依存しない作り方が決まっていない。

### 7.4 札

読み手ごとに 1 つ。上から順に評価する。閾値はすべて入力（§4.1）。既定値は ⚠ 仮置き。

    u₂ / n ≥ ι（仮置き 0.3）         → 計器不良（根拠 id の捏造・形式崩れが多い）
    u₄ / n ≥ κ（0.708）              → 計器不良（両側に証拠が出た軸が多い。全問 Yes の読み手はここで止まる）
    (s + r) / n < ρ（仮置き 0.5）    → 本文に根拠が無い
    w ≤ ω（0.400）かつ p > 0.5       → 偏り（支持）
    w ≤ ω かつ p < 0.5               → 偏り（反証）
    それ以外                          → 割れる

読み手をまたぐ要約: 読み手間 Δ > 0.117 → `読み手が割れた`。

値の出所（測定 2 周目 M4・命題 21・行 42・標本内 51。`.pair-agent/agreements/measurement-2.md`）:
κ は健全側の最大 0.417 と全問 Yes の偽読み手 1.0 の中点。ω は「割れる」想定と「偏り」想定の w の取り違えが最小の値（11 本で当てて新規 10 本で 0/0）。
Δ は標本内 |p 差| の 95% 分位。ι は既知不良が無く昇格できない。ρ は根拠なしの命題でも生成器が本文の周辺事実を軸にするので有効率が 0 にならず、分離点が置けない。
⚠ **値はすべて仮説**（師匠 2026-09-22）。題材集合が変われば引き直す。汎用的な値に落とすのが方針。

⚠ **偏りの札は「本文の中で命題が片側に倒れている」の意味**であり、読み手の偏りではない。
読み手の一律の偏り（全問 Yes に寄る等）は、軸の両側に証拠が出る形で**矛盾（u₄）に現れる**。
v1 は「差で打ち消える」と書いていたが、比の推定量では打ち消えず 0.5 側へ減衰するだけだった。
v2 の同数の記述では p = 0.5・w = 1 の「割れる」に化けた。対の軸（p3）では矛盾率 1.0 で「計器不良」に止まる（S11）。

### 7.5 診断値（確からしさの材料）

LLM に申告させない。数えられる量を**そのまま並べて返す**。1 つの数に畳まない（⚠ J6′）:

| 診断値 | 何を表すか |
|---|---|
| 有効率 (s + r) / n と、観点ごとの有効率 | 本文に根拠があった軸の割合。観点ごとの差が片側性 |
| 判定不能率・記述なし率 u₁ / n | 本文の沈黙。**0% は forced-choice の合図** |
| 無効率 u₂ / n | 根拠 id が本文に無かった割合（計器の健全性） |
| 標本間の一致率 | 同じ読み手の標本で方向が一致した割合 |
| 追加生成の回数と、追加生成された問いの判定不能率 | H1 の同数強制がどれだけ空振りしたか |
| 矛盾率 u₄ / n | 軸の両側に証拠が出た割合。読み手の偏りと、生成器の対の非排他性の合算（p3 実測: qwen 0.11 / gemma 0.12 / 全問 Yes 1.00） |
| 軸ごとの向き | 各軸の d と両側の答え・根拠 id。**∀ 型の命題（「すべて満たす」）は多数決では表現できない**ので、利用側がここから自分の集約（必須軸の min など）を作る |

読み手をまたぐ要約には**読み手間の差**（度合いの最大 − 最小、段の一致）を一級項目として置く（Q1 の計器）。

### 7.6 型付け（L4）

| 型 | 値 |
|---|---|
| 真偽確率 | p |
| 順序尺度（K 段） | p が落ちる段。段の境界は利用側が渡せる。既定は K 等分（⚠ 仮置き。「段 3 とは何か」はドメインの知識なので、既定に意味を持たせない） |

値は型から構成的に作るので、型の外に出る経路が無い（Q2）。札が `本文に根拠が無い` / `計器不良` のときは値なし。

## 8. 記録（監査と蒸留の素材）

1 判定につき、追記のみで残す:

- 入力: **本文の単位列（id ＋ 本文）**・命題・型・予算・閾値。⚠ ハッシュだけでは再計算も第三者検証もできない
- 問いの集合（§5.1）＋ 生成器の名前 ＋ 生成指示の版 ＋ 単位化規則の版
- 回答行列（§5.2）＋ 読み手の名前 ＋ 回答指示の版 ＋ 生応答
- 集約結果（§7）＋ 集約規則の版

生応答が残るので、規則を変えても**再計算だけ**で新しい結果が出る（Q7）。
「分布 → 結論」の対がそのまま蒸留（L5）の学習データになる（概念文書 §3.3）。

## 10. 解かないこと・適用限界（v1）

- **型の中の誤りは防げない**。判定不能・根拠 id の門は「根拠の無い答え」を落とすだけで、判断の正しさは保証しない
- **H2（観察可能）は検査されていない**。根拠 id の実在照合は関連性を見ない。候補: (a) 別の読み手に「この単位はこの問いの答えを支持するか」を答えさせる（それ自体が判定で、再帰する）、(b) 問いに本文中の語を最低 1 つ含めさせる（機械検査できるが弱い）。v1 は S5 で人が測る
- **読み手が共有する一律の偏り**（肯定に寄る等）は、両観点同数だけでは検出できない（§7.4）。未決 U1
- **軸の独立性は保証されない**。意味の重複は未検証（H4）
- **確からしさは較正されていない**。診断値を並べて返すところまで。1 つの数には畳まない
- **本文が 1 回の文脈に入らない長さ**は拒否（F1）。分割・要約は判断を生成に委ねる経路になるので別の題として設計する
- **順序尺度の各段の確率**は返さない（§7.3）
- **∀ 型の命題（「すべて満たす」「揃っている」）は度合い（多数決）では表現できない**。m05（3 要件中 2 充足）で p 0.60〜1.00。
  軸ごとの向きを返すので、利用側が「必須軸の min」で集約する。どの軸が必須かはドメイン知識（README 約束 2）
- **本文そのものについての命題**（記載の有無・完全性）では、「書かれていない」が `否定している` なのか `触れていない` なのかが読み手に委ねられる。
  弱い読み手は `触れていない` に倒す（S14）。読み手の指示で直す案は測定 2 周目で不採用（根拠なしの命題に漏れる）。
  生成器側で反証側を「本文が実際に含むものの肯定文」にするブループリント（`doc/PSYCHOMETRICS_SURVEY.md` 候補 3）が次の題
- **生成器の向きの誤り**は交差検証（H12・既定 ON）で外す。強い生成器では 2.6%、弱い生成器では評価的な命題で 6 軸中 3 軸（S13）
- **読み手が本文を記憶している場合、判定は本文ではなく記憶から出る。** 羅生門（青空文庫）で強い読み手 3 体とも p=1.00、
  老婆の言い分を変えた反事実で 0/6 動かず、本文を渡さない腕と答えが同一。**反事実（S10）で追従しない本文の値は報告しない。**
  運用では検出項目（同 候補 1: 本文に明らかにある記述と絶対に無い記述）で毎回測る必要がある
- **読み手が弱いと読み手間で割れる**（4B 級で Δ 0.155）。強い読み手では割れは消える（Δ 0.03、標本間の差 0）。
  弱い読み手を使う利用側は読み手 2 体以上と `読み手が割れた` の札を前提にする
- **単一系統でも判定は偏らない（実測 1 家系）**: gemma4 を生成器・読み手・検証役にしても、多系統との |p 差| 中央値 0.00、
  想定一致 16/19 で同じ、向きの誤りの自己検出 7 軸（他系統 5 軸）。⚠ 強いモデル 1 家系・21 題材での結果。弱い単一系統は未測定
- **ラベル集合（名義尺度）の型**は v1 の範囲外。「各ラベルを命題にして one-vs-rest」で組めるが、後で決める
- **複合文の命題**は検出しない（F7）
- **外部知識が要る命題**（本文に無いことを知っていないと答えられない）は判定不能になる。それが正しい
- 文章の作成・多段推論は対象外（README）

## 12. 未決だったもの（2026-09-22 に確定）

協議エンジンの評価で「実装の既定で足りる」と判定したものは §11 に落とした（本文の長さ・生成器のモデル依存・接続ライブラリ）。
残る 3 つは、空撃ち（題材 11・弱い読み手 2）で測り、**判断規則に照らした読み**を付けて師匠に問うた。
**師匠決定（2026-09-22）: 「確定でよい。」** — U1〜U3 は以下の形で確定。

### U1 「対立を含む」の核 — 測定結果: 軸ごとの排他な対（C の形）

- v2 の「支持観点と反証観点の記述を同数」は、度合いを構造的に 0.5 に固定した（p2: 22 件中 15 件）。**核として不成立**
- 軸を「支持側／反証側の排他な対」にすると本文が対称性を破り、想定に合った題材 10/11（p3）
- 両側に証拠が出た軸は矛盾として除き、矛盾率を計器の健全性として返す。矛盾率 qwen 0.11・gemma 0.12・全問 Yes 1.00。
  標本内のばらつき 0.06 を超えるので、判断規則どおり **C**（矛盾率を返す）
- ⚠ 矛盾の出所は「読み手が両側に述べている」と「生成器の対が排他でない」の混合。分けるには対の排他性の検査が要る（未検証）

**問い**: 「Y,N 両方の観点から問い、割れるのか偏るのかを判定する」を、**軸ごとの対**（各軸に Y 側と N 側の記述）として実装した。この読みで確定してよいか。

### U2 「度合い」は何の割合か。段は誰が切るか — 測定結果: 等重み多数決 ＋ 軸ごとの向きを返す（B ＋ 利用側の後処理）

- 度合い = 有効な軸のうち支持側に倒れた割合。等重み。段の境界は利用側が渡せる（既定 K 等分・仮置き）
- ∀ 型の命題（m05「すべて満たしている」: 3 要件中 2 充足）は多数決では表現できず p 0.60〜1.00 になった。
  **軸ごとの向きを返し、利用側が「必須軸の min」などで集約を差し替えられる**形にする。どの軸が必須かはドメイン知識なのでライブラリは持たない

**問い**: 度合いの既定は等重み多数決のまま、段の境界と∀ 型の集約は利用側、で確定してよいか。

### U3 読み手が割れたとき — 測定結果: 割れるのは現実。読み手ごとの値と差を一級で返す

- 読み手間 Δ 平均 0.15・最大 0.40、段の一致 5/11。標本内の |p差| 平均 0.06。Δ は標本内のばらつきを系統的に超える
- 割れた例の中身: 弱い読み手の読み違い（m05 gemma「大阪に勤務できる」を述べているとした）が主
- 判断規則どおり「読み手が割れた」は現実。読み手ごとの度合い・段・札と Δ を返し、代表値は読み手ごとの度合いの平均（仮置き）。
  札「読み手が割れた」の閾値は実分布から。仮置き Δ > 0.2（観測した Δ の中央値 0.175 の近傍。⚠ 弱い読み手 2 体・題材 11 の値）

**問い**: 代表値は平均で始め、Δ > 0.2（仮）で「読み手が割れた」の札を立てる、で確定してよいか。強い読み手で Δ が縮むかは別の空撃ちで見る。
